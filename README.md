# SDUST 第二课堂自动报名脚本

山东科技大学第二课堂活动的本地自动报名工具。脚本通过 WebVPN 的 CAS 统一身份认证登录，自动读取可报名活动，并在指定开抢时间高频提交报名请求。**全程在本地运行，无需服务器，密码仅在运行时输入、不会写入任何文件。**

> 仅用于 Python 学习与技术交流，请先阅读文末[免责声明](#免责声明)。

## 功能特性

- 自动完成 WebVPN → CAS 统一身份认证 → 第二课堂 Token 换取的完整登录链路；
- 复刻 CAS 前端 RSA 密码加密逻辑，与网页端结果一致；
- 读取首页可报名活动并列出，支持手动输入活动 ID；
- 自动进行**服务器时间校准**，到点毫秒级触发；
- 多线程高频提交，内置登录抖动重试、Token 失效自动重登；
- 纯 Python 实现，可在电脑、安卓 Termux / Pydroid 3 运行。

## 工作流程

1. 运行时输入学号与统一认证密码；
2. 脚本走 CAS 登录并换取第二课堂访问 Token；
3. 拉取可报名活动，用户选择目标活动并确认开抢时间；
4. 脚本倒计时等待，临近开抢自动刷新登录；
5. 到点后多线程高频提交报名，确认成功后停止。

## 环境要求

- Python 3.8 及以上；
- 依赖库：`requests`；
- 运行设备需能访问 `webvpn.sdust.edu.cn`（校园网或已联网环境）。

## 安装与使用

### 电脑（Windows / macOS / Linux）

```bash
# 1. 克隆项目
git clone https://github.com/<你的用户名>/sdust-ekt.git
cd sdust-ekt

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行
python sdust_baoming.py
```

### 安卓手机（无电脑）

- **新手推荐**：安装 Pydroid 3，按 [`Pydroid3使用说明.md`](Pydroid3使用说明.md) 图形化操作；
- **Termux**：参考 [`Termux部署使用说明.md`](Termux部署使用说明.md)。

### 交互说明

启动后按提示依次输入：学号 → 密码 → 活动序号（列表为空输 `0` 手动填 ID）→ 开抢时间（直接回车用活动自带时间，或输入 `YYYY-MM-DD HH:MM:SS`）→ 线程数（默认 8，直接回车）。

## 安全说明

- 密码通过 `getpass` 在运行时读取，**不硬编码、不写盘、不上传**；
- 建议在安全的网络环境运行，并定期修改统一认证密码；
- 线程数不建议设置过高，避免对服务器造成压力。
